## Processing and observation details

- **HiRISE:** [The preparation script](scripts/prepare_jezero.py) reads STAC, the source PDS label, processing notes and bounded HTTP ranges from the two USGS COGs. Exact COG URLs and local validation are recorded in [validation.json](public/data/terrain/jezero-hirise-1km/validation.json). The outputs are a 1 km², 500 × 500 grid at 2 m spacing centered at 18.44° N, 77.45° E, with Float32 elevations in metres above the Mars2000 areoid, validity mask, aligned imagery and derived hillshade. The bundled [STAC item](public/data/terrain/jezero-hirise-1km/source-stac-item.json) lists an inconsistent observation datetime; do not cite it as capture time. Use the stereo IDs `ESP_045994_1985` and `ESP_046060_1985`. See [technical provenance](docs/DATA_SOURCES.md).
- **MEDA:** Sol 1, ATS sensor 1: 253.31 K at LTST 15:27:28 (SCLK 667042430), product window 2021-02-19 21:35:20.970–22:05:14.984 UTC. Derived pressure, transducer 2: 715.96 Pa at LTST 15:28:01 (SCLK 667042464), product window 2021-02-19 21:35:54.970–22:29:54.996 UTC. The windows are product bounds, not sample times. The pressure uncertainty field is blank for the selected row.
- **MCD:** SCI-04 requests t (K), p (Pa), u/v (m/s), at 18.44° N, 77.45° E, 2 m above ground, solar longitude 270°, local true solar time 12:00. The source requests set `var1=t&var2=p&var3=u&var4=v&datekeyhtml=1&ls=270&localtime=12&latitude=18.44&longitude=77.45&altitude=2&zkey=3`, with `dust=1` (reference, average solar), `dust=7` (warm dusty, maximum solar), and `dust=5` (global dust storm, average solar). The provider returns HTML. Keep the cached numbers, the reports/screenshots showing them, and all commits containing them out of the public release unless redistribution is confirmed. A future candidate can use independent synthetic scenarios with clear labels or omit those scenarios; removing files from a descendant of SCI-04 would leave the original values in Git history.

## Other assets and software

The project uses a custom browser map and elevation chart, Lucide icons, locally available system fonts and a project favicon. Inter is a CSS preference only; no font file is bundled or downloaded. The tracked project screenshots show the application. The stable browser build does not include NASA Mars Trek, a remote basemap, a third-party map library, a runtime AI service or another scientific API. The separate challenge candidate is documented below. Test endpoints and synthetic fixtures are not scientific sources. React, Vite, npm packages and the Python preparation toolchain are listed in [Third-party notices](THIRD_PARTY_NOTICES.md). NASA and mission credits are source attribution, not endorsement; see [NASA media guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/).
