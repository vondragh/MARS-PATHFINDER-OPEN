# Архітектура MARS PATHFINDER

## Призначення

Desktop-first науковий прототип для конфігурації EVA, огляду синтетичного рельєфу та підключення зовнішніх terrain/routing модулів. Поточний UI повідомляє про DEMO/SYNTHETIC дані та відсутність наукової валідації.

## Межі модулів

- `src/domain/terrain/` — метадані, affine transforms, координатний sampling і перевірка raster contract.
- `src/domain/routing/` — незмінний контракт запиту/результату й runtime validation.
- `src/adapters/demo/` — відтворюваний фронтенд-адаптер для демонстрації; не є науковим алгоритмом.
- `src/adapters/scientific/` — місце реєстрації модулів SCI-01/SCI-02; наукові обчислення не дублюються тут.
- `src/hooks/` — стан місії, інвалідація попередніх результатів, скасування та захист від застарілих async відповідей.
- `src/components/` — місійна форма, інтерактивна SVG карта, аналіз і профіль висот.

## Перетворення координат

Raster affine transform переводить pixel-corner `(column,row)` у локальні метри. Sampling бере `floor` координат пікселя й відхиляє точки поза сіткою/NoData. Synthetic fixture має окрему сферичну equirectangular трансформацію тільки для демонстраційного підпису lat/lon; вона не поширюється на реальний dataset.

## Асинхронні обчислення

Кожен розрахунок отримує унікальний `requestId` і `AbortSignal`. Зміна точки, обмежень, optimization mode або reset скасовує попередній розрахунок і прибирає старий результат. Frontend перевіряє відповідь до збереження.

## Науковий статус

`REAL DATA` означає наявність джерельного набору з provenance. Це не означає валідацію алгоритму. Статус SCI-03 окремий; у демо відображається `REVIEW PENDING`.
