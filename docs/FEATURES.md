# Website feature audit

**Scope:** [production](https://mars-pathfinder.pages.dev/), release [`002b6cdf`](https://github.com/vondragh/MARS-PATHFINDER-OPEN/tree/002b6cdf1a03365ed2241b997afc43bb34714764), reviewed 15 November 2026. Chrome interactions were run on desktop (1440 × 1000), with the core route and imagery workflow repeated on mobile (390 × 844). Failure checks deliberately blocked individual network requests or delayed worker dispatch. Source inspection and the automated suite supplement the browser checks.

No broken implemented core workflow was reproduced in these checks. Hosted desktop and mobile route/imagery flows had no JavaScript errors. The induced failures generated expected network errors. The test suite also exercises route contracts, elevation data, worker/adapter behavior, unavailable data and UI state.

## First-time judging experience

A default comparison is practical within one minute: choose **Compare routes**, select both results and open **Jezero context & science evidence**. The live site makes route planning and scientific caveats visible, but does not directly link to the competition presentation or source repository. The [README](../README.md) serves as the submission entry point for both links, the live demo, exact deployed source and scientific evidence. Do not treat the one-minute path as a timed usability study.

See the [step-by-step guide](USER_GUIDE.md), [scientific method](SCIENTIFIC_METHOD.md) and [source credits](../DATA_SOURCES.md).
