# SCI-01: метод підготовки та інтеграції

## Відтворення

```sh
python3 -m venv /tmp/mars-sci01-venv
/tmp/mars-sci01-venv/bin/pip install -r scripts/requirements-sci01.txt
/tmp/mars-sci01-venv/bin/python scripts/prepare_jezero.py
```

Команда перегенерує лише похідний каталог Jezero. Джерельні серверні файли не змінюються. SHA-256 поточних локальних артефактів, версії GDAL/rasterio/numpy, запити Range та контрольні відліки містяться у validation.json.

## Геометрія і одиниці

Фактичний COG: глобальна Mars spherical EQC, R=3396190 м, lat_ts=0, lon_0=0. Його affine не містить skew, але глобальні EQC метри по X не можна прирівнювати до локальної наземної відстані на 18.44° N. PROJ переводить координати COG через planetocentric lon/lat у локальну EQC з lat_ts=lat_0=18.44°, lon_0=77.45°.

`x=R*cos(lat0)*(lon-lon0)`, `y=R*(lat-lat0)`; кутові різниці — у радіанах. Цільові вектори колонок/рядків (2,0) і (0,-2) м, їхній скалярний добуток нуль. Кути ±500 м, центри ±499 м. Перевірка сферичною геодезичною відстанню в центрі дала 1.9999999999364517 м між сусідніми колонками. Масштаб трохи змінюється поза центральною паралеллю.

## Висоти, маска та зображення

Nearest-neighbor reprojection не створює нових інтерпольованих висот. Scale та offset DEM застосовано рівно один раз; вертикальна трансформація не виконується. Вихідні значення — метри над Mars2000 areoid відповідно до source label. Зміна горизонтального CRS не змінює datum висот.

Маска валідності переноситься minimum resampling: якщо footprint містить невалідність, вихід не приймається як валідний. NoData записується NaN і valid=0, заповнення прогалин немає. У конкретному фрагменті всі 250000 комірок валідні. Це не означає, що всі комірки безпечні або мають однакову точність.

Ортофото перепроєктовано на точно ту саму сітку 500×500 і affine. PNG — grayscale 2–98 percentile stretch з alpha mask; це візуалізація, не радіометричний або hazard-продукт. Додатковий hillshade обчислений із DEM, не є незалежним спостереженням.

## Маршрути та перевірки

Браузер читає canonical TerrainDataset через loadTerrainDataset. SCI-02 працює у Web Worker, отримує ортогональну сітку без повторного resampling; алгоритм Timur не змінено. Обидва режими оптимізації повертають геометрію у локальних метрах і профіль вихідних висот. Початкові Habitat/Point A/B — приклади планування, не підтверджені наукові цілі.

Результат A* означає існування шляху в межах моделі. Окремо оцінюються slope, EVA час із науковою активністю та резервом, наявність hazard layer і незалежна наукова валідація. Валідація SCI-03 та операційна придатність не встановлені. Стереопомилки, jitter, шви та ручна інтерполяція джерела можуть впливати на похідні ухили.

Для всіх вихідних валідних центрів незалежне зворотне перетворення у source grid підтвердило точний nearest source sample: максимальна різниця висоти 0 м. Це перевірка реалізації resampling, а не абсолютної точності DEM.
