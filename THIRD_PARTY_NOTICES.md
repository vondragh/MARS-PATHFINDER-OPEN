## Build and preparation tools

The complete npm distribution inventory is pinned in [package-lock.json](package-lock.json), including optional platform dependencies. The build uses Vite 6.4.6 and its React plugin, TypeScript, Vitest, jsdom and Testing Library. The lock declares MIT, ISC, MIT-0, Apache-2.0, BSD-2-Clause, BSD-3-Clause and CC-BY-4.0 (build-time caniuse-lite). Preserve each package's own notices if redistributing dependencies or build tooling.

The separate [SCI-01 preparation requirements](scripts/requirements-sci01.txt) pin Rasterio (BSD-3-Clause), pyproj (MIT), NumPy (BSD-3-Clause), Pillow (HPND), and certifi (MPL-2.0). Python packages, bundled native libraries and certificate bundles are not part of the browser deployment. Review their individual notices if redistributing Python wheels or an executable preparation environment.
