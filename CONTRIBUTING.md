# Contributing

Describe the problem, its impact and a way to reproduce it. Keep changes scoped; explain any changes to SCI-01 or SCI-02 contracts and coordinate them with their owners. Start from the intended base branch and propose a pull request after running `npm ci`, `npm run typecheck`, `npm test` and `npm run build`. For UI changes, include desktop and mobile checks. Update the relevant Ukrainian technical documentation when scientific inputs, assumptions or outputs change.

Submit only work you have the right to contribute. Identify all copied or adapted code and assets, retain required attribution and notices, and disclose material AI assistance. For scientific data, record the source product, version, license, units, transformations, validation and limitations. Keep credentials, personal information, original large rasters and generated output out of commits.

Original contributions are intended for Apache-2.0; third-party inputs keep their own terms. Security and privacy findings should follow [SECURITY.md](SECURITY.md).
