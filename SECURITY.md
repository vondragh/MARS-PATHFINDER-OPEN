# Security

The maintained release line is the stable application published from `main`; development branches are not release builds.

Report a suspected vulnerability or private data exposure through GitHub's **Security → Report a vulnerability** form once private vulnerability reporting is enabled. Until that channel has been verified, contact a maintainer privately through an established team channel. Do not post exploits, credentials, private links or personal information in a public issue.

Include the affected version or commit, reproduction steps and impact. Redact sensitive values. If you discover an exposed credential you control, revoke or rotate it promptly; removing a file does not remove the credential from Git history.
